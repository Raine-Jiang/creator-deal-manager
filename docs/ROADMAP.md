# Roadmap

- Personal deal tracking
- Login
- CRUD for deals
- Product image upload
- Mobile-first PWA interface
- Supabase-backed persistence

- CSV / Excel export
- Better product image replacement and deletion

- More robust mobile visual QA

- Dashboard / finance summary
- Calendar view
- Brand archive
- Deal status filters
- Reminder list for publish, payment and refund dates
- Manual backup export from the app

## V3

- Multi-device notification reminders
- Multi-user collaboration
- Brand CRM notes
- Attachment library
- Deal templates for repeated brands
