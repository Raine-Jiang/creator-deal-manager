# Product Spec

## User

The primary user is a dance creator who publishes frequent sponsored videos on Xiaohongshu and Douyin.

## Core Problem

Creator deals are scattered across chat messages and personal notes. The creator needs one reliable place to track:

- What deals were accepted
- Which products have arrived
- When filming or publishing is due
- How much money is owed
- Which advances or refunds are still pending

## V1 Product Principle

V1 should be simple enough to use every day. The product favors fast entry, clear reading and reliable persistence over advanced automation.

## Required Deal Fields

All business fields are optional so a creator can save incomplete deals early and edit them later.

- Brand
- Product
- Platform
- Product image
- Product price
- Base fee
- Commission
- Advance amount
- Received date
- Shoot date
- Publish deadline
- Actual publish date
- Expected payment date
- Expected refund date
- Product URL
- Publish URL
- Notes

## UX Notes

- Mobile-first
- White cards on a light system background
- Bold black page titles
- Muted secondary labels
- Soft pastel accents
- Form rows use consistent left label and right value alignment
- Hide empty fields in cards and detail screens
