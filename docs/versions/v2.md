# V2 Notes

## Objective

Turn Creator Deal Manager into a practical daily operating app for managing deals, schedule pressure, money and daily creator revenue.

## Scope

- Stronger app-like visual style.
- Fixed bottom navigation.
- Home dashboard with lightweight operational summaries.
- Deal status and lifecycle improvements.
- Immediate quick record toggles with exportable action history.
- Calendar based on `publish_deadline`.
- Finance range filters and category analysis.
- Daily creator revenue tracking.
- Excel import/export.
- Trash, restore and permanent delete.
- Batch management with current-filter select all.
- Profile name/avatar/password tools.
- Low-token project context documentation.

## Important Decisions

- `publish_deadline` is the primary business date for calendar and finance.
- Completed deals are archived automatically and should not be treated as a separate concept from completed.
- Daily creator revenue is separate from deal commission.
- The daily revenue editor should stay compact: one selected day, previous/next buttons and fixed-width date chips.
- Keep the project lightweight for free Vercel and Supabase tiers.

## Current Acceptance

The user confirmed that this is suitable as the second version.
