# V1 Notes

## Objective

Build the first stable version of Creator Deal Manager as a personal mobile-first PWA.

## Scope

- Email/password login.
- Supabase database, storage and auth.
- User-isolated deal data through RLS.
- Deal list, new deal form, detail page and edit page.
- One product image per deal.
- Vercel deployment.
- Basic app-like visual direction.

## Out Of Scope

- Calendar.
- Finance dashboard.
- Daily creator revenue.
- Excel import/export.
- Brand CRM.
- Multi-user collaboration.
- Notifications.

## Important Decisions

- V1 required a real backend because local-only data would be unsafe across refresh, login, images and devices.
- Supabase was chosen for low-cost auth, database and storage.
- Vercel was chosen for free production hosting and fast iteration.
